# 円形紋章ゲームアニメーション PoC

> 注意: これは技術評価用の PoC です。MiniMax H3 の重みや画像生成モデルなど、使うモデルの利用条件に従い、**非商用の評価に限って**使ってください。生成物を商用利用する前に各モデルのライセンスを確認してください。

## 目的

新規の透過円形紋章を原画として、MiniMax H3でゲーム用ループVFXを複数生成し、
RGBA PNG列・スプライトシート・透過動画へ変換する。

## 完了条件

- 透過RGBAの円形紋章原画を作成・保存
- pulse / counter-spin / activation の3モーションを生成
- 全モーションをPNG列、sprite sheet、VP9 alpha、ProRes 4444へ出力
- alpha、フレーム数、ループ先頭末尾差を検証
- 成果物ファイルの取得確認

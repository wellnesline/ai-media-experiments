## 1. 人間版 アニメ制作パイプライン (本編 30 分の場合)

```
①企画・脚本     プロデューサ + 脚本家 + 監督
   ↓ (シナリオ)
②絵コンテ      演出/監督 が「映像の設計図」 を描く
   ↓ ★この PoC はここに相当 → 単調になりやすい根本原因
③レイアウト    原画マンが各カットの構図・キャラ配置を清書
   ↓
④原画         動きの中心(キーフレーム)を作画
   ↓ (1 話 300+ カット)
⑤動画 (中割)   原画間を補完
   ↓
⑥彩色         デジタルペイント
   ↓
⑦背景         美術が描く
   ↓
⑧撮影         AE 等で合成・エフェクト
   ↓
⑨編集         尺合わせ・色調・MIX
   ↓
完成
```

**重要**: 絵コンテ段で「面白さ」 の 8 割が決まる。 ここを雑にやると後工程で挽回不可能。

## 2. 絵コンテで使われる用語(この PoC の shots.py に未実装のもの中心)

### ショットサイズ (距離・切り取り方)

| 略称 | 名称 | 切り取り方 | 用途 |
|---|---|---|---|
| **ELS** | Extra Long Shot | 全身が小さく入る引き | シーン冒頭、 場所説明 |
| **LS** | Long Shot | 全身 | 環境+キャラ関係性 |
| **MLS** | Medium Long Shot | 膝上 | ニトラル説明 |
| **MS** | Medium Shot | 腰上 | 会話標準(この PoC は全カットがこれ) |
| **MCU** | Medium Close-Up | 胸上 | 会話の感情寄り |
| **CU** | Close-Up | 顔 | 感情・表情 |
| **ECU** | Extreme Close-Up | 目・口・指等 | 強調・象徴 |

### カメラアングル

- **正面 / 三分の二 / 真横 / 後ろ姿**
- **アオリ** (低い位置から見上げる) → 威圧・優越
- **フカン** (高い位置から見下ろす) → 弱さ・憐れみ
- **POV** (主観視点)
- **OTS** (Over-the-Shoulder、 肩越し) → 会話の臨場感

### カメラワーク

- **PAN** カメラ横振り
- **TILT** 縦振り
- **TU/TB** トラックアップ/バック (寄り/引き)
- **ZOOM**
- **FIX** 固定
- **フォロー** 被写体追従

### 演出記号

- **IN/OUT** フレーム外との出入り
- **AC** アクションカット (前後の動きを繋ぐ)
- **OL** オーバーラップ (重ね合わせ転換)
- **F.I / F.O** フェードイン/アウト
- **画面動** 揺れ(爆発・着地)
- **なめる** カメラ手前に何か配置(奥行き感)
- **OFF/IN セリフ** 画面外からの声 / 画面内のキャラのセリフ

## 3. カット割り 5 原則 (これが PoC に欠けてる)

### 原則 1: 引き → 寄り の流れ

「外景 → 室内全景 → 二人入りの引き → 一人ずつ寄り → 表情アップ」 と段階的に寄っていく。
**観客に「ここはどこ、 誰がいる、 何が起きてる」 を順に提供**する。

### 原則 2: マスターショット を最初に押さえる

シーン冒頭に二人(or 全員)が入る LS を 1 カット入れておく。
以降の切り返しがすべてこのマスターを基準に「位置関係」 を保つ。

### 原則 3: アクションとリアクションのセット

A: (大胆な宣言のセリフ) (キャラA MS)
B: 聞き手の目がスッと細まる ECU (0.5s リアクション)
C: (冷めた返し) (キャラB MS)

**リアクションがないとセリフが平坦に響く**。 漫才も同じ理屈で、 ボケのあとツッコミ顔が決め手。

### 原則 4: インサート で情報密度を上げる

セリフ中にキャラだけでなく:
- **作業台の上の帳面**(キャラBが書き込んでいる記録)
- **キャラAの手の中の種袋** (ラベルの表示)
- **工房の温度計、 吊りランプ、 工具箱**

を 0.5-1.5 秒の短いインサートで挟むと **情報の幅 + テンポ** が両立する。

### 原則 5: ピローショット で呼吸を作る

セリフのない 1-2 秒の風景・象徴ショット:
- 揺れる吊りシダ
- ガラス越しの夕焼け
- 部品札が並んだ棚

**緩急のリズム**。 ずっと顔顔顔だと観客が疲れる。

### 補助原則: イマジナリーライン (180度ルール)

二人を結ぶ仮想線の片側にカメラを置いたら、 続くカットも同じ側から撮る。
**逆側に飛ぶと「向かい合っている」 関係性が逆転して混乱**を生む。
キャラAが画面左にいるなら、 キャラAのアップでも視線は画面右向き。

## 4. テンポ(カット秒数)の原則

| カット長 | 用途 |
|---|---|
| **0.3-0.8 秒** | アクション・驚き・リアクション・インサート瞬間カット |
| **1-3 秒** | 標準会話、 説明、 通常テンポ |
| **3-5 秒** | 感情を見せたい、 大事なセリフ |
| **5+ 秒** | じっくり描写、 風景、 余韻 |

**現代の TV CM は平均カット秒数 1.4 秒** (StudioBinder 調査)。 短いほうがテンポ良い。

**30秒に 8-15 カット入れる**のが TV CM の標準。 1 カット平均 2-3 秒。

## 5. この PoC の課題 (単調に見える原因)

| 項目 | 現状 PoC | 人間版アニメ |
|---|---|---|
| カット数 | N (1 セリフ = 1) | **35-50** (1 セリフを 2-3 カットに分解) |
| ショットサイズ | ほぼ全部 MS | **LS/MS/CU/ECU 混在** |
| カメラアングル | ほぼ正面 | 正面 + アオリ + 三分の二 + OTS |
| カット秒数 | 2-6 秒均一 | **0.5-6 秒の不均一**、 急減でテンポ作る |
| マスターショット | 無し | 各 P scene 冒頭に 1 カット |
| リアクションショット | 無し | 話者の合間に頻繁挿入 |
| インサート | 無し | 小物・指・スマホ画面で密度up |
| ピローショット | 無し | カーテン・時計等で呼吸 |
| イマジナリーライン | 守られてるか不明 | 二人の位置関係厳守 |

→ **「絵本」 になってる**。 「動画」 にするには上記を全部入れる必要あり。

## 6. 改善ロードマップ (PoC 仕切り直し)

### Step A: shots.py の根本再設計

旧スキーマ (1 line = 1 shot) を捨て、 新スキーマに移行:

```python
SCENES = [
    {
        "scene_id": "P1",
        "lines_total_sec": 10.4,   # 合成音声の合計(例)
        "lines": [
            {"idx": 0, "speaker": "char_a", "text": "...", "duration": 5.2},
            {"idx": 1, "speaker": "char_b", "text": "...", "duration": 5.2},
        ],
        "shots": [
            # 1 SCENE 内で 4-6 カットに割る
            {
                "id": "C001",
                "kind": "establishing",         # 確立ショット
                "shot_size": "LS",
                "camera": "FIX",
                "duration": 1.0,                # 短い
                "covers_lines": [],             # セリフ無し
                "is_pillow_or_insert": True,

    },

```

P1 (旧 2 shots、 10秒) → 新 6 cuts、 約 12秒 (やや尺超だが調整可)。

### Step B: shot kind の語彙

- `establishing` 確立(LS、 場所説明)
- `master` マスター(LS or MLS、 二人入り)
- `action_main` 主アクション(MS、 話者中心)
- `reaction` リアクション(MCU/CU/ECU、 聞き手)
- `insert` インサート(ECU、 小物・文字)
- `pillow` ピロー(LS/MS、 セリフ無し風景)
- `cta` クロージング

### Step C: 視聴者を退屈させない経験則

- **同一 shot_size を 2 連続させない** (MS のあと MS で別カットは単調)
- **3-4 cut に 1 回は ECU or LS** (緩急)
- **話者交代時に必ず切り返し** (リアクション or 別アングル)
- **5 秒超のセリフは 2 cut に割る** (途中で寄ったり引いたり)
- **マスターショットを 30 秒に 1 回は入れる** (場所感覚リセット)

### Step D: 試算 (新方式)

P1-P5 を新方式で再分解すると 概算:

- P1 (約 10 s) → 6 cuts
- P2 (約 19 s) → 9 cuts
- P3 (約 14 s) → 7 cuts
- P4 (約 17 s) → 8-9 cuts
- P5 (約 8 s) → 4 cuts

合計 約 **35 cuts**(現状の 2 倍以上)、 約 68 秒 (audio 変わらず)。

コスト:
- 静止画 約35枚 × $0.02 = $0.70
- Kling i2v(主要カットのみ動かす、 ピロー/インサートは静止)
  - 動かすカット 20 本 × $0.20 = $4.00
  - 静止カット 15-20 本 × $0 (静止画 + ffmpeg ken-burns)
- 合計 PoC 制作費 約 **$5**

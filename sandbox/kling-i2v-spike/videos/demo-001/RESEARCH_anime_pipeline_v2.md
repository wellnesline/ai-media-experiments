## A. カメラ「動き」 (camera_move) 種類と使い所

| 略 | 名称 | 動き | 演出意図 | 使い所 |
|---|---|---|---|---|
| **FIX** | 固定 | 動かさず | 静寂・落ち着き・観察 | 会話/状況描写 |
| **PAN** | 横振り | カメラ位置固定+左右回転 | 視線誘導・場所紹介 | 環境ショー・人物追従 |
| **TILT** | 縦振り | 上下回転 | 高さの強調・スキャン | 全身→顔/タワー紹介 |
| **TU (TI)** | トラックアップ/push-in | 前進 (寄り) | **緊迫感・親密・感情ピーク** | 重要セリフ・気づき瞬間 |
| **TB** | トラックバック/pull-back | 後退 (引き) | **突き放し・全体露見・孤独感** | 場面終了・距離感・締め |
| **DOLLY** | 平行移動 | 横スライド | 観察者視点・追従 | キャラと一緒に歩く |
| **TRACK** | 追従 (dolly に近い) | 横/縦移動 | 動きと一体感 | アクション・歩き |
| **FOLLOW** | 被写体追随 | カメラがキャラと一緒に | 視聴者を主観に置く | 走り・追いかけ |
| **RACK FOCUS (ピン送り)** | ピント送り | 手前→奥 or 逆 | **注目対象切替・視線誘導** | 二人会話で発話者切替 |
| **DOLLY ZOOM (ヴェルティゴ)** | 矛盾移動 | 寄りつつ画角広く | **めまい・心理的混乱** | 衝撃・恐怖の表現 |
| **HANDHELD** | 手持ち | 微振動 | 臨場感・不安 | ドキュメンタリー風・パニック |
| **CRANE/JIB** | クレーン | 上下大きく | 神視点・大きい移動感 | 場面開始・終了の俯瞰 |

**寄り (TU) = 心情強調、 引き (TB) = 状況強調**(基本ルール)

## B. カメラ「角度」 (angle) 種類と心理効果

| 角度 | 効果 | 例 |
|---|---|---|
| **eye level** (水平) | 中立・自然 | 普通の会話 |
| **アオリ (low angle)** | **支配・力強さ・畏怖** | 威圧する人物 / ヒーロー登場 |
| **俯瞰 (high angle)** | **弱さ・支配される側・小ささ** | 落ち込み / 子供視点 |
| **真俯瞰 (bird's-eye / top-down)** | **神視点・全体俯瞰・運命的** | 戦況図 / 重要オブジェ |
| **Dutch angle (傾き)** | **不安・混乱・狂気** | 悪夢・緊迫・捻れた心理 |
| **POV (主観)** | **観客=キャラ・没入** | 振り向き先の発見 |
| **OTS (over-the-shoulder)** | **会話の臨場感・力関係** | 二人対話・密度 |

## C. 構図 (composition) 原則

| 技法 | 効果 | 適用例 |
|---|---|---|
| **Rule of thirds** | 動的・自然 | 交点に主役、目線は上 1/3 ライン |
| **Leading lines** | 視線誘導 | 床線・廊下・手の指す先 |
| **Depth layering (3層)** | 立体感・没入 | 前景=なめる/中景=主役/背景=環境 |
| **Frame within frame** | 注目焦点・密室感 | ドア越し/窓越し/額縁越し |
| **Negative space** | 感情余韻・余白美 | キャラ片寄せ・上空空白 |
| **Symmetry** | 静寂・秩序 | 神聖シーン・対峙 |
| **Asymmetry** | 動・緊張 | 通常シーン |
| **Diagonal lines** | 躍動感 | 階段/レール/視線軸 |
| **Overlapping** | 立体感 | 前後の重なり |
| **Tangent 回避** | スッキリ視認 | 線が接さない halo gap |
| **なめる (foreground silhouette)** | 没入感・覗き見 | 手前にぼかしオブジェ |
| **High/low contrast 配色** | フォーカス | 明暗で誘導 |
| **形状感情**: 円=親しみ / 四角=秩序 / 三角=攻撃 | 潜在的印象 | キャラポーズ・小物形状 |

## D. コメディ timing & visual gag

### 鉄則 (Educational Voice / AWN 由来)

1. **「リアクションのほうがボケより面白い」** — 必ずリアクション切り替えを入れる
2. **間 (pause for effect)** — 笑いの前に 0.3-0.8 秒の沈黙を置く
3. **Double take (二度見)** — 「えっ」 → 「ええっ!?」 の段階リアクション (1 cut 目軽い反応、 2 cut 目大爆発)
4. **誇張表現** (exaggeration) — 漫画的に目を見開く / のけぞる / 汗ドロップ拡大
5. **rule of three** — 1, 2 は普通、 3 でオチる構造
6. **音声と映像のテンポずらし** — voice-over starts before cut to speaker (foreshadowing)
7. **smash cut to reaction** — 連続する説明→突然のリアクション ECU で笑いに振る

### 一枚絵 i2v 動画 で効くパターン (本 PoC 適用)

- 登場カット → ECU で目元の反応 = 「またか」の予兆
- 自慢 → ECU 反応 → さらに自慢 = double take 構造
- デッドパンな一言 → 相手の顔がこわばる = smash cut to reaction
- ボケ → 聞き返し → 呆れ = setup + payoff (3 line で rule of three)

## E. トランジション (cuts 間のつなぎ)

| 技法 | 説明 | 使い所 |
|---|---|---|
| **cut (基本)** | 単純切り替え | 標準 |
| **match cut** | 同形状/同動作で繋ぐ | 場面転換・時間飛ばし |
| **eyeline match** | 視線方向と一致するカット | 会話切り替え (180度 ルール準拠) |
| **action match** | 動作の途中で切り替え | 動作のスムース感 |
| **smash cut** | 急変・対比 | コメディ・衝撃 |
| **jump cut** | 時間飛ばし (連続シーンで一部省略) | 焦り・ダイジェスト |
| **dissolve (OL)** | 重ね合わせ | 時間経過・夢想 |
| **fade (F.I/F.O)** | 暗転 | 章区切り・始末 |
| **pin focus shift (rack)** | ピント送りで対象切替 | 二人の発話者切替 |

## F. 単調さ打破チェックリスト (絵コンテ完成後 必読)

シート全体を見直して、 以下を順番にチェック:

1. **全カットが MS/MCU だけ** になってないか? → LS, CU, ECU を各 SCENE に最低 1 つ
2. **全カットが eye level の正面** か? → アオリ/俯瞰/Dutch/OTS を散らす
3. **全カットが FIX** か? → 1 SCENE につき最低 1 つの camera_move (TU/TB/PAN/RACK)
4. **establishing / master が無い** → SCENE 冒頭 or 30 秒に 1 回挿入
5. **リアクションショットが無い** → 話者交代点に 0.3-0.7s のリアクション
6. **インサート (小物・文字 ECU) が無い** → SCENE に 1 つは insert
7. **5 秒超のセリフが 1 cut** → 必ず 2 cut に分割 (異なる shot_size or angle)
8. **同じ shot_size が 3 連続** → 1 つを違うサイズに差し替え
9. **同じ角度が 3 連続** → 1 つを違う angle に差し替え
10. **コメディ beat に payoff のリアクション無い** → smash cut to ECU 反応を挟む

このリストを通過したら絵コンテは「動く動画」 として最低限のクオリティを満たす。

    "angle": "eye" | "low" | "high" | "bird" | "dutch" | "POV" | "OTS",
    "composition": ["rule_of_thirds", "depth_3_layer", "frame_in_frame", ...],   # list
    "beat_purpose": "setup" | "escalation" | "payoff" | "pause" | "button",      # コメディ beat 機能

scene_desc には camera_move / angle / composition の指示を明示的に含める (画像生成に効く)。
motion_prompt には camera_move (TU/TB 等) の動きを 1 句で記述する。

## H. 「映像作家っぽくする」 ための小ネタ集

- **シルエット ショット**: 逆光でキャラがシルエットになる → 雰囲気の強い ESTABLISHING
- **reflection (反射)**: 鏡 / ガラス / 水面 越しに撮る → 内省・自己観察
- **silhouette frame**: 前景に手やドアを置いて被写体を切り抜く
- **handheld for emotion**: 感情ピーク時にカメラを微振動させる
- **rule of three の 3 つ目だけサイズ変える**: 1MS, 2MS, 3CU (escalation)
- **eye line above third**: 重要キャラの目線は frame の上 1/3 ライン
- **長尺カットの中で内部展開**: 1 カット内で PAN したり TU したりして単調回避
- **edit on motion**: アクション match cut で滑らかに繋ぐ
- **negative space dump**: 重要セリフの直後に 1-2 秒のピロー (空・カーテン等)
